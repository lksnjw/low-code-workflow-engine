## Architectural invariants

| Invariant | Status | Evidence |
|---|---|---|
| LLM never holds ERP credentials | PARTIAL | Provider clients hold only model-provider credentials and runner/MCP is separate, but generated/resolved parameters are supplied to tools and the LLM repair prompt includes failing YAML and error text (`backend/internal/core/synthesizer/gemini_client.go:66-83`, `backend/internal/core/healing/error_loop.go:25-38`, `backend/internal/tools/mcp_client.go:60-83`). No test proves ERP credentials cannot enter the repair prompt. |
| LLM never calls ERP directly | ENFORCED | Synthesis clients call model endpoints; ERP calls occur only through `Tool.Execute`/MCP (`backend/internal/core/synthesizer/gemini_client.go:66-83`, `backend/internal/core/runner/executor.go:164-184`, `backend/internal/tools/mcp_client.go:60-101`). Import-boundary tests keep validator/runner dependencies separated (`backend/internal/core/context/import_boundary_test.go:10-38`). |
| LLM output is candidate, not command | PARTIAL | Chat validates every generated and repaired candidate before selection (`backend/internal/core/orchestrator/chat_orchestrator.go:116-172`, `backend/internal/core/orchestrator/chat_orchestrator.go:188-200`). Baseline B converts a rejected candidate/workflow into executable input (`backend/internal/api/handlers/execute_handler.go:50-83`). |
| Repairs undergo full revalidation | ENFORCED for both bounded repair paths | Chat repair calls the same candidate validator, and execution healing calls `validateWithFullGate`; execution repair is not automatically re-run (`backend/internal/core/orchestrator/chat_orchestrator.go:121-139`, `backend/internal/api/handlers/execute_handler.go:106-134`; tests `backend/internal/core/orchestrator/chat_repair_test.go:20-105`). |
| Recovery bounded; terminal state reached | PARTIAL | Healer defaults to one attempt and the handler ends as FAILED; startup reconciles orphaned RUNNING records (`backend/internal/core/healing/error_loop.go:11-23`, `backend/internal/api/handlers/execute_handler.go:95-142`, `backend/cmd/server/main.go:101-104`). Cancellation is a STUB and a process crash can leave RUNNING until restart (`backend/internal/api/handlers/execute_handler.go:453-455`, `backend/internal/api/handlers/execute_handler.go:547-579`). |
| Policy violations never heal | ENFORCED on the normal path | Only transient failures enter healing, and policy/data-egress errors are excluded (`backend/internal/api/handlers/execute_handler.go:95-139`; tests `backend/internal/api/handlers/gate_invariant_test.go:180-213`, `backend/internal/api/handlers/execution_status_test.go:81-100`). Baseline B prevents the violation from becoming an error (`backend/internal/core/runner/executor.go:135-145`). |
| Validator makes no network call | ENFORCED | Validator imports registry/models/repository/parser only and evaluates local registry snapshots (`backend/internal/core/validator/registry_validator.go:3-21`, `backend/internal/core/validator/registry_validator.go:55-69`, `backend/internal/core/validator/registry_validator.go:242-268`). Context independence is tested (`backend/internal/core/context/mdgen_test.go:166-200`). |
