# Data and persistence

The runtime store is a single map-backed object containing users, sessions, roles, workflows, versions, executions, logs, timelines, healing, chats, settings, integrations, audit records, notifications, API keys, and uploads (`backend/internal/repository/memory.go:28-60`). Default `STORAGE_DRIVER=memory` loses all of that on restart (`backend/internal/config/config.go:127-130`, `backend/internal/storage/storage.go:19-29`).

PostgreSQL mode is IMPLEMENTED as one AES-GCM-encrypted, versioned whole-state blob. Every write unlock serializes and synchronously upserts the blob; one advisory lock permits only one writer (`backend/internal/repository/persistent_store.go:18-40`, `backend/internal/repository/persistent_store.go:52-102`, `backend/internal/storage/postgres.go:58-77`, `backend/internal/storage/postgres.go:97-113`). Migrations exist, but business entities are not normalized relational tables; the schema boundary is the `persistedState` envelope (`backend/internal/repository/persistent_store.go:201-228`, `backend/internal/storage/postgres.go:152-178`).

The store lock makes each in-process mutation plus snapshot atomic, and persistence failure rolls back to the last committed plaintext snapshot (`backend/internal/repository/persistent_store.go:78-100`, `backend/internal/repository/persistent_store.go:152-172`). This is durable when PostgreSQL is selected, but not tamper-resistant: audit records are mutable members of the same replaceable blob (`backend/internal/repository/persistent_store.go:219-228`, `backend/internal/repository/memory.go:231-236`).

Multi-tenancy is NOT FOUND after searches for `tenant`, `tenant_id`, `organization_id`, and query scoping. Ownership/assignment scoping exists for workflows and executions, but the data models contain no tenant/organization key (`backend/internal/models/workflow.go:52-76`, `backend/internal/models/state.go:36-52`).

Redis construction is discarded at startup and no policy cache participates in validation; cache TTL/version behavior is therefore NOT FOUND (`backend/cmd/server/main.go:72-73`, `backend/internal/config/redis.go:1-21`). The audit shape captures actor/action/resource/IP/user-agent/before/after/time, while gate evidence is nested in `After`; model and policy versions are absent (`backend/internal/models/user.go:59-69`, `backend/internal/core/validator/registry_validator.go:1042-1065`).
