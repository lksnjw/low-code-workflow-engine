# Integration contracts

| Boundary | Actual wire contract and status | Reliability / validation / failure |
|---|---|---|
| Governance/policy | No separate governance HTTP client was found using searches `governance`, `policy api`, `RAG` in backend clients. Policy is an IMPLEMENTED local runtime rule registry loaded from JSON (`backend/cmd/server/main.go:140-151`, `backend/internal/core/validator/registry_validator.go:242-268`). | Validator makes no network call and therefore fails closed on local parse/rule failure; external governance version negotiation is NOT FOUND (`backend/internal/core/validator/registry_validator.go:3-21`). |
| ERP data/semantic pipeline | Semantic search POSTs a query/options JSON to configured `SEMANTIC_SEARCH_URL`; external mode is default (`backend/internal/core/semanticsearch/service.go:42-119`, `backend/internal/config/config.go:146-153`). | HTTP timeout is 12 seconds; optional lexical fallback is configuration-controlled, otherwise error is returned (`backend/internal/core/semanticsearch/service.go:42-119`). Response is decoded into typed structs but not version-negotiated (`backend/internal/core/semanticsearch/models.go:1-47`). |
| MCP bridge | `POST <MCP_BASE_URL>/tools/execute` with `{action, parameters}`; any status below 400 plus JSON object is accepted (`backend/internal/tools/mcp_client.go:60-101`). Remote and explicit mock modes share the adapter (`backend/internal/tools/mcp_client.go:47-67`, `backend/internal/tools/mcp_client.go:104-119`). | Client timeout is configured; no transport retry, idempotency key, response schema validation, or version negotiation exists (`backend/internal/config/config.go:134-135`, `backend/internal/tools/mcp_client.go:69-101`). Empty URL and HTTP errors fail closed. |
| LLM provider | Gemini `POST /models/{model}:generateContent`, Ollama `POST /api/generate`, and OpenAI-compatible `POST /chat/completions` use typed response decoding (`backend/internal/core/synthesizer/gemini_client.go:47-131`, `backend/internal/core/synthesizer/ollama_client.go:253-308`, `backend/internal/core/synthesizer/openai_client.go:34-87`). | 45/60-second HTTP timeouts; no automatic generation retry except one higher-level candidate repair. Missing configuration/errors fail closed for candidate production (`backend/internal/core/synthesizer/ollama_client.go:60-80`, `backend/internal/core/orchestrator/chat_orchestrator.go:116-140`). Provider output becomes only a candidate on the normal path (`backend/internal/core/orchestrator/chat_orchestrator.go:121-172`). |

The interface/adapter split is real for LLM providers and MCP mode, but live compatibility cannot be guaranteed by config alone because MCP response schemas and tool/version negotiation are absent (`backend/internal/core/synthesizer/ollama_client.go:176-233`, `backend/internal/tools/mcp_client.go:89-101`). The validator itself uses only local registries and store state, preserving deterministic decisions (`backend/internal/core/validator/registry_validator.go:47-69`, `backend/internal/core/validator/registry_validator.go:127-203`).
